# ADR-0011: 세이브 v7 — 대포·선체·화물칸 레벨 재척도

- 날짜: 2026-10-16 · 결정: S1(사용자 지시 '돈이 너무 많이 벌린다' 골드 재조정의 후속) · 작성: S2

## 배경
골드 재조정(1f52fc3)으로 대포·선체·화물칸은 '강화 1번 = 예전 3레벨'이 됐다(성장·비용 성장 세제곱, milestone 25 → 8, 외형 문턱 1/3).
옛 레벨을 새 공식에 그대로 넣으면 값이 터무니없이 커진다(S4: stage37 픽스처 화물칸 ×1.25e13, S3: 배 HP 1.4e10).

## 결정
- `schemaVersion` 7. `migrateV6ToV7`: `ship.parts`의 cannon·hull·cargo를 3으로 나눈다(올림 — 강화한 사람이 손해 보지 않게).
- 돛·망루는 레벨당 효과가 그대로라 바꾸지 않는다. 명예 외형(`ship.honor.parts`)은 레벨이 아니라 단계라 그대로.
- 픽스처 `test/fixtures/saves/v7.json`. 시나리오 상태(fixtures/states, v6)는 러너가 불러올 때 마이그레이션된다.

## 결과
- 옛 세이브의 전투력·외형 단계가 새 공식에서 대략 같게 이어진다(올림만큼 조금 이득).
