## 1. 수집하지 않는 것
- 회원가입·로그인이 없습니다. 이름, 이메일, 전화번호, 위치, 연락처, 사진을 수집하지 않습니다.
- 게임 진행 기록(세이브)은 **기기 안에** 저장되며 개발자에게 전송되지 않습니다. 앱을 삭제하면 함께 지워집니다.
  기기의 Android 자동 백업이 켜져 있으면 세이브가 **사용자 본인의 Google 계정 백업**에 포함되어 새 기기에서 복구될 수 있습니다(Android 기능이며 개발자는 볼 수 없습니다).

## 2. 제3자 서비스가 처리하는 정보
| 서비스 (제공자) | 목적 | 처리하는 정보 |
| --- | --- | --- |
| Google AdMob (Google) | 보상형 광고 표시·측정·부정 방지 | IP 주소(대략적인 위치 추정에 쓰일 수 있음), 광고 ID·앱 세트 ID, 기기·OS·진단 정보(실행 시간 등), 광고 상호작용(실행·누르기·시청) |
| Google UMP (Google) | 광고·분석 동의 받기(유럽 등) | 동의 선택 값 |
| Firebase Analytics (Google) | 이탈 분석·게임 개선 | 화면 보기, 마지막으로 본 화면·스테이지, 게임 이벤트(현상금 사냥 시작·성공·실패, 도감 발견 — 보스 이름·단계·보상 수치), 앱 인스턴스 ID, 광고 ID, 마스킹된 IP로 추정한 대략적인 위치, 기기·OS 정보 |
| Firebase Crashlytics (Google) | 오류 수정 | 충돌 기록(스택 추적), 충돌 시점의 화면, 기기·OS 정보, 설치 ID |

- 이 정보로 개인을 식별하려 하지 않으며, 판매하지 않습니다.
- Google의 처리 방식: https://policies.google.com/technologies/partner-sites
- 광고는 **보상형만** 있으며, 사용자가 보상 버튼을 눌러 원할 때만 봅니다. 실제 돈 결제는 없습니다.
- 유럽경제지역·영국·스위스 사용자는 첫 실행 때 동의 창이 뜨며, **동의 전에는 광고 요청과 Analytics 수집을 하지 않습니다.**
  동의는 게임 설정의 "개인정보 옵션"에서 언제든 바꿀 수 있습니다.
- **충돌 기록(Crashlytics)은 앱 안정성을 위해 동의와 관계없이 수집합니다**(광고·추적에 쓰지 않음). `<결정 대기 — data-safety.md 4절: 동의 뒤로 묶으면 이 줄을 지운다>`
- 이 정보는 Google이 서비스 제공자로서 처리하며, AdMob은 광고 제공을 위해 Google 광고 네트워크와 정보를 공유합니다.

## 3. 기기 권한
- **알림**: 오프라인 보상이 가득 찼을 때 하루 최대 1번 알림을 보냅니다. 기기 안에서 예약되는 로컬 알림이며 서버를 거치지 않습니다. 게임 설정 또는 기기 설정에서 끌 수 있습니다.
- **인터넷**: 광고와 분석에만 씁니다. 연결 없이도 게임은 진행됩니다.
- 광고 ID는 기기 설정(Android: 설정 > 개인정보 보호 > 광고)에서 재설정·삭제할 수 있습니다.

## 4. 보관 기간과 삭제
- 세이브: 기기 안, 앱 삭제 시 삭제.
- Analytics: Firebase 보존 기간 설정 `<미정 — 2개월 또는 14개월, 사용자 결정 대기>` 후 자동 삭제. Crashlytics 충돌 기록: 90일.
- 분석 데이터 삭제를 원하면 repo.dev88@gmail.com으로 요청하세요. 앱 인스턴스 ID를 확인할 수 있게 안내합니다.
