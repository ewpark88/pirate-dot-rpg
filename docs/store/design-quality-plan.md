### 1.2 공통 패턴 (근거 있는 것만)
1. **핵심 반복 버튼은 아래쪽 엄지 자리** — 하단 탭은 5개 이하가 한 손 조작 표준([Smashing](https://smashingmagazine.com/2020/02/design-mobile-apps-one-hand-usage/), [UX Planet](https://uxplanet.org/one-handed-use-of-tab-bar-bottom-navigation-best-practices-for-reachability-73376377444b)).
2. **세로 흐름 = 위 상태(적 HP·재화) · 가운데 전장 · 아래 조작·메뉴.**
3. **팝업·버튼이 전장 정보를 가리면 바로 감점**(버섯커). 이벤트·광고는 아이콘·배지로 접는다.
4. **"다음에 뭘 할지"를 표시**(Recommended 태그, 버프 타이머 아이콘). 시스템이 늘수록 더 중요.
5. **도트 게임의 호평 = 친숙한 도트 + 덜어낸 UI**(메이플 키우기). 장식 추가보다 정보 정리가 먼저.
6. **연출은 업데이트마다 조금씩 올리고, 강한 피드백은 끌 수 있게**(Idle Slayer).
7. **큰 숫자 표기를 일관되게 정하고 설명**(Tap Titans 불만).

### 1.3 사람이 10분 캡처 (미확인 채우기, 선택)
메이플 키우기·버섯커 키우기·Legend of Slime·Tap Titans 2를 설치해 세로 화면을 캡처하면 아래를 재서 이 표에 넣는다:
전장 높이 비율 · 상단 바 높이와 항목 · 하단 탭 수·이름 · 떠 있는 버튼 수 · 숫자 표기 · 피해 숫자 크기·색 · 오프라인 보상 창 모양.
캡처를 `docs/specs/benchmark/<게임>.png`에 두면 S5가 측정해 비교 그림을 만든다.

## 2. 우리 게임 실기기 캡처와 비교한 차이

배치 v2 brief의 A1~D1(전장 25%·버튼이 배를 가림·빈 슬롯 띠·5열 이름 끊김·글자 작음 등)은 **1단계에서 이미 고치는 중**이라 여기선 번호만 잇는다.
아래는 그 밖에 벤치마크 패턴과 캡처를 맞대어 본 차이다.

| # | 패턴 | 우리 게임 지금 (S24 캡처) | 단계 |
| --- | --- | --- | --- |
| E1 | 위에 재화 | 골드·젬이 화면 어디에도 크게 안 보임(캔버스 HUD 골드는 버튼 밑) — 방치형의 1차 정보 | ① (v2 상단 바) |
| E2 | 패널 위계 | 모든 패널이 같은 남색·같은 1칸 테두리. **테두리 대비 1.8:1**(바탕 남색 대비)이라 패널 경계가 거의 안 보이고, 화면이 한 덩어리로 보인다. 글자 대비는 충분함(흰 글자 16.5:1, 흐린 글자 6.3:1, 골드 10.4:1 — WCAG AA 4.5 이상) → 문제는 **색이 아니라 크기·경계** | ② |
| E3 | 버튼 모양 일관성 | 배 탭 강화 버튼은 파란 도트 버튼, 소환은 납작한 파란/남색 상자, 퀘스트 보상은 빈 네모 '+10', 복귀 창 '확인'은 글자 | ①(v2 C1·C2) + ② 스킨 |
| E4 | 엄지 자리 핵심 버튼 | 소환 버튼이 위쪽에 작게(높이 약 40dp), 아래 절반 비어 있음. 배 탭은 오른쪽 열에 있어 엄지 닿음 | ① |
| E5 | 다음 행동 표시 | 목표 띠(“대포 도약까지 5레벨”)는 좋다. 탭 배지(빨간 점)는 퀘스트에만. 강화 가능·소환 가능·합치기 가능 배지 없음 | ② |
| E6 | 미보유 선원 | 선원 탭 대부분이 검은 실루엣 → 화면 전체가 어둡고 무겁다 | ② (실루엣 밝기·잠금 테두리) |
| E7 | 아이콘 체계 | UI 아이콘 26장. 크기(16~28px)·윤곽 두께·광원 방향이 섞임(예: 탭 아이콘은 컬러 큰 그림, 배 부위 아이콘은 작은 그림) | ② |
| E8 | 전장 연출 밀도 | 피해 숫자는 많지만 **배 앞에서 겹쳐 쌓여 읽히지 않는다**(스토어 스크린샷 01·02). 물보라·연기·빛 없음, 바다가 평평한 띠 | ③ |
| E9 | 해역 다양성 | 심연·유령 해역의 적 8종·보스 4종 그림 없음(대체 도형) | ③ 전에 아트 |
| E10 | 전환·소리 | 탭 전환·창 열림이 즉시(애니 없음), 버튼 소리 없음, 효과음 미등록(자작 칩튠 선택됨, ogg 등록 대기) | ④ |
| E11 | 큰 숫자 | `352ac`·`19ad` 같은 표기 — 장르 표준이지만 처음 보는 사람에게 설명 없음 | ② (도움말 1줄) |

## 3. 퀄리티 단계안

각 단계는 **실기기 캡처 비교로 끝낸다**: 같은 화면 5장(항해·배·선원·소환·퀘스트)을 S24에서 찍어 이전 단계 캡처와 나란히 놓고, 아래 완료 기준을 하나씩 체크.
도구: `store_shots_test.dart`(STORE_SHOTS)로 384×832·dpr 2.8125 화면을 자동으로 굽고, 사람은 실기기로 마지막 확인.

### ① 가독성·배치 — 진행 중 (layout-v2)
- 할 일: brief 그대로(상단 바, 전장 폭 채우기 38~42%, 전장 위 버튼 제거, 선원 줄 6칸+궁극기, 4열, 본문 14sp, 창 버튼 통일).
- 담당: render(S3)·ui(S4). 규모: 진행 중.
- 완료 기준: 전장 위 누르는 버튼 0개 · 내 배·보스·스테이지 글자 안 가림 · 재화가 상단 바에 · 360/384/411dp 넘침 0 · 선원 이름 한 줄 · 실기기에서 사용자가 "읽힌다".

### ② UI 스킨 통일 — "한 게임처럼 보이게"
- 할 일
  1. **해적 테마 프레임 3단 위계**를 그림(9-slice PNG)으로: 화면 바탕(진한 나무/남색) · 카드(밝은 테두리 2칸 + 모서리 장식 리벳) · 강조(금색 테두리, 추천·보상). 지금 코드 프레임(`PixelFrame`)은 그대로 두고 그림 슬롯만 받게.
  2. **버튼 4종 상태**(기본·눌림·비활성·추천 반짝임) × 3색(주=파랑, 보상=금, 위험=빨강), 높이 단계 40/48/64dp.
  3. **아이콘 규격**: 16px 격자 하나(정수 배율), 윤곽 1px 같은 색(`outline`), 광원 왼쪽 위. 26장 다시 맞춤 + 빠진 것(배지·잠금·추천).
  4. **배지 규칙**: 할 수 있는 행동(강화 가능·소환 가능·합치기 가능·보상 받기)에 탭 배지 + 버튼 반짝임 — 패턴 4.
  5. 미보유 선원: 실루엣을 바탕보다 2단계만 어둡게 + 잠금 테두리(검정 덩어리 → 회색 카드).
  6. 숫자 표기 도움말 1줄(설정 또는 처음 aa가 나올 때 한 번).
- 담당: **art(S3)** 프레임·버튼·아이콘 그림(약 40~50장) → **ui(S4)** 적용(PixelFrame·PixelButton에 그림 슬롯, 배지). 규모: 아트 2~3세션, ui 2세션.
- 완료 기준: 캡처 5장에서 **버튼 모양 3종 이하**(지금 5종 이상) · 패널 경계가 실기기에서 보임(테두리 대비 ≥3:1) · 아이콘 전부 같은 격자·윤곽 · 할 수 있는 행동마다 배지 · 선원 탭 평균 밝기 상승(측정: 탭 영역 평균 휘도 +30% 이상).

### ③ 전장 연출 밀도 — "볼 맛"
- 할 일
  1. **숫자 정리**: 같은 대상·같은 틱 피해는 합쳐 1개(범위는 이미 합계), 배 앞 겹침은 위로 비켜 쌓기, 큰 숫자만 크게.
  2. 파티클: 물보라(적 처치·포탄 착수), 포연, 코인 반짝임, 배 항적(물결 흰 띠).
  3. 빛: 폭발 순간 주변 밝게(가산 혼합 1~2프레임), 해역별 하늘 색조·시간대 띠.
  4. 배경 깊이: 하늘·먼 섬·가까운 물결 3겹 시차 스크롤(v2에서 늘어난 하늘·깊은 바다 칸을 채움).
  5. 해역 아트 공백 채우기(심연·유령 적 8·보스 4) — 이 단계 전에.
- 담당: **render(S3)** + art(S3) 파티클 시트. 성능 예산은 기존 기준(p95 ≤ 16.7ms, 부하 장면) 유지.
- 완료 기준: 스토어 스크린샷 01·02에서 숫자가 겹쳐 안 읽히는 곳 0 · 부하 장면 성능 기준 통과(저사양 1대 포함) · 설정의 흔들림·번쩍임 끄기로 강한 연출이 꺼짐(패턴 6) · 사용자 "볼 맛 난다".

### ④ 폴리시 — 전환·소리·손맛
- 할 일
  1. 전환: 탭 전환 슬라이드(도트 스텝 4프레임), 창 열림 확대(정수 배율 3단), 보상 숫자 올라가며 세기, 소환 카드 뒤집기 다듬기.
  2. 소리: 효과음·배경음 등록(자작 칩튠 + CC0 3곡, S1 진행) → UI 소리(버튼 딸깍·코인·탭 전환) 추가, 연출 타이밍과 맞춤(폭발 프레임 = 소리 시작).
  3. 손맛: 진동(설정 존중) 강도 3단, 보스 처치 순간 히트스톱 다듬기.
  4. 로딩·스플래시 → 첫 화면까지 끊김 없이(스플래시 색 = 첫 화면 바다색, 이미 맞춤).
- 담당: ui(S4) 전환 · render(S3) 연출 싱크 · platform(S5) 소리 어댑터·진동 · art(S3) 소리 파일 정리.
- 완료 기준: 실기기 화면 녹화 30초(전투·탭 전환·소환·보상)에서 끊김·즉시 전환 0 · 모든 버튼에 눌림 상태+소리 · 소리와 연출 어긋남 체감 없음.

## 논의할 것 (사용자 결정)
1. **순서**: ②(UI 스킨)와 ③(전장 연출) 중 무엇을 먼저? 추천: 둘 동시. 사람 눈엔 ③이 먼저 띄지만, 리뷰 감점은 ②(조잡한 UI) 쪽이 크다(버섯커 사례).
2. **스킨 방향**(②): ⓐ 지금 남색 + 금 강조를 다듬기(빠름) / ⓑ 해적 나무·밧줄·양피지 테마(분위기↑, 아트 많음) / ⓒ 섞기(바탕 남색 유지, 카드·버튼만 나무·금). 추천 ⓒ.
3. **벤치마크 캡처**(1.3): 사람이 4게임 10분 캡처해 수치를 채울지, 이대로 갈지.
