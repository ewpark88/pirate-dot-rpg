# 계획: 보스 공격 진짜 회피(예고 때 비켜서면 빗나감) — S5 설계, S2 boss-feel 뒤 구현

- 2026-10-17 · S5 · 요청: S1(⑤ '보스 공격 예고 때 옆으로 빠르게 회피 대시'), S2 '보스 리듬 재조정이 겹치니 boss-feel 뒤에'.
- 상태: 설계(코드는 `bossDuel.dodge` 겉모습 회피만 있고 표 키 없음 = 꺼짐, review/ship-motion).

## 1. 지금 판정 (game_core topdown/boss_patterns.dart)
| 패턴 | 예고(warnSec) | 맞는 순간 | 위치를 보나 |
| --- | --- | --- | --- |
| volley(탄 n발) | 0.6초 | 비행 틱 뒤 `EnemyShot` 도착 | **아니오** — '배는 움직이지 않으니 늘 맞는다'(탄은 발사 때 배까지의 거리로 비행 틱만 정함) |
| blast(배 둘레 원) | 0.6초 | 예고 끝 틱 | **아니오** — 예고한 원 안에 배가 있다고 보고 바로 `_hurt` |
| charge(돌진) | 0.6초 | 보스가 배 몸통에 닿을 때 | 예 — 지금 배 쪽으로 직진(따라옴) |
| summon·ink·swallow | — | 피해 없음 | — |
→ 회피 대시를 켜도 volley·blast는 늘 맞고 charge는 따라와서 맞는다. 겉모습뿐이라 꺼 둠(켜면 이동으로 사거리가 흔들려 러시 신화가 오히려 침몰).

## 2. 제안 규칙 (표 키 `waves.top.bossDodge`, 없으면 지금 그대로)
1. **조준 고정**: 예고 시작 틱에 배 자리(aimX·aimY)를 패턴에 기록한다(`BossPlan.aimX/Y`).
2. **volley**: 각 탄이 aim을 향해 날아가고, 도착 틱에 배 몸통 캡슐과 탄 반경(`shellRadius`)이 겹칠 때만 피해. 아니면 `ShellMissed`(물보라).
3. **blast**: 원 중심 = aim. 터질 때 배 몸통이 원(`radiusShipMul × shipRadius`)과 겹치면 피해, 아니면 `BlastMissed`.
4. **charge**: 예고 끝에 aim 방향으로 **곧게** 돌진(따라오지 않음), `chargeOvershoot`만큼 지나치면 복귀 — 몸통에 닿을 때만 피해.
5. **배의 회피**: 예고 중 배가 결투 자리에서 옆(보스 방향의 수직)으로 `dodge.dist`를 `dodge.speed`로 비킨다(지금 코드 그대로). 비키는 쪽은 패턴마다 번갈아 — 결정론.
6. **피할 수 없는 패턴**은 표에서 `homing: true`(예: 대보스 필살기)로 지금처럼 늘 맞게.

## 3. 밸런스 (S2)
- 회피가 성공하면 보스 피해 기대값이 줄어든다 → 성공률 p를 재서 보스 `damageRatio` × 1/(1−p)로 보정하거나, 일부만 피하게 `dodge.dist`를 blast 반경보다 작게.
- 측정: 같은 시드로 dodge 끔/켬 × 중반·신화 × 보스 23종 — 패턴별 맞힘률, 보스전 배 피해 합, 보스 처치 시간. 목표: 보스전 침몰률은 그대로, '피했다' 장면이 보스전마다 1~2번.
- 순항(feverOnly)과 무관 — 보스전은 결투 비켜서기만.

## 4. 렌더·UI (S3·S4)
- 예고 표식은 aim 자리에 고정(지금은 배를 따라감) — 배가 빠져나가는 게 보이게.
- `ShellMissed`·`BlastMissed`: 빗나감 물보라 + 'MISS'(선원 MISS와 다른 색).

## 5. 단계
1. S2 boss-feel 머지 확인 → 이 문서 S2 검토.
2. 엔진: aim 기록·판정·이벤트 2개·표 키(기본 꺼짐) + 시험(정지 배는 늘 맞음 = 지금과 같음, 비키면 빗나감, homing은 늘 맞음).
3. 탐침 표 → S2 수치 → 표 키 켬 → S3 연출 → 골든 일괄.
