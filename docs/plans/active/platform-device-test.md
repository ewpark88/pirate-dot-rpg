## 3. 플랫폼 확인 — 광고·알림·저장·이름 (약 15분)
```bat
flutter run --profile -d <기기id> --dart-define=OPERATOR=true
```
- `google-services.json`이 없으면 분석은 꺼진 채로 돈다(정상). 광고는 **테스트 광고**("Test Ad" 표시)만 나온다 — 실제 광고를 누르지 않는다.
- 터미널 로그에서 `ads:`·`notify:`·`analytics:`·`audio:`·`save:`로 시작하는 줄이 실패 이유다. 문제가 있으면 그 줄을 함께 보낸다.

### 결과를 받으면 (S1 → platform)
- 광고(2·3)·알림(4·5)·저장(7) 이상 → platform 레인에 로그 줄과 함께. SDK 연결 파일(`google_ads_sdk`·`local_notifications_sdk`·`firebase_sdk`·`flame_audio_sdk`)은 단위 테스트가 없어 여기가 유일한 확인이다.
- 6 이름 → 영문 이름 확정되면 `res/values/strings.xml`만 바꾼다.
