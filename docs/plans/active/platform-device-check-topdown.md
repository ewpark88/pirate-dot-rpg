# 실기기 확인 — 탑다운 v2 (아침 15분) — S5 → S1

- 2026-10-16 저녁 갱신(전판 10-15 밤). 오늘 들어간 기능 기준: 배 위협(원거리 적·가까이 등장)·돌격대·피버 오라·지그재그·보스 패턴·바다 괴물 돌진·선원 개성 v2(조준·MISS)·보호막·낙뢰·피버 서포트·신화 폭발·빠른 항해 돌파·현상금·운영자 선원 시험.
- 준비: S1이 release를 설치한다(`python -I -B docs/store/device/release_smoke.py` 통과 뒤). ★ 줄은 운영자 빌드(`--dart-define=OPERATOR=true`)에서만 된다.
- 사용자는 '볼 것'만 보고 각 줄에 **OK / 이상 + 한마디**만 적어 S1에게 준다(예: "7 이상 — 지그재그가 너무 빠름").
- ★ 운영자 줄을 하기 전에: 패널 '저장'에서 샘플을 불러오면 **내 세이브가 자동 백업**된다. 끝나면 **'내 세이브로 돌아가기'**(14번).
