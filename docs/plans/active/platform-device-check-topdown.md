# 초안: 실기기 확인 — 탑다운 (내일 아침 10분) — S5 → S1

- 2026-10-15 밤 작성 · S1이 docs/DEVICE_TEST.md 1절(손맛)을 이것으로 바꿀지 결정. 옆모습 문구('오른쪽에서 몰려온다')는 이제 틀리다.
- 준비: S1이 release를 설치한다(`release_smoke.py` 통과 뒤). 운영자 기능이 필요한 줄(★)은 운영자 빌드(`--dart-define=OPERATOR=true`)에서만 된다.
- 사용자는 표의 '볼 것'만 하고, 각 줄에 **OK / 이상 + 한마디**만 적어 S1에게 준다(예: "4 이상 — 숫자가 너무 많아 배가 안 보임").
