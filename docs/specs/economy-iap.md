# 유료 상품(IAP) 기획 — S2 초안 (2026-10-17, 사용자 검토용)

사용자 요청: '유료 상품도 고민해서 추가해라. 2배속을 유료로 살 수 있는 상품, 광고 제거(1개월은 싸게·영구는 비싸게) 같은 수익 상품 — 예시니까 다른 것도 구성해라'.
다음 단계: S5 결제 어댑터(Google Play Billing·App Store), S4 상점 화면. 계약(세이브 권리 구조)은 S1 승인.

## 1. 원칙
1. **무과금도 같은 끝까지, 과금은 시간 단축.** 끝 콘텐츠(해역·대보스·신화 선원·도감 40명)는 모두 무과금으로 닿는다. 돈으로 사는 것은 시간(배속·젬)·편의(광고 없이 보상)·꾸밈(스킨)이다.
2. **직접 전투력 판매는 최소.** 선원 등급·배 부위 레벨·공격력 배수를 바로 파는 상품은 없다. 젬(→ 소환)만 간접 전투력이고, 소환은 무료로도 꾸준히 들어온다(보스 첫 처치 젬·도감·출석·광고).
3. **광고 제거 = '보상형 광고를 보지 않고 바로 보상'.** 우리 게임엔 강제 광고가 없다(보상형만). 광고 제거를 사면 광고 버튼이 '바로 받기'가 되고 **하루 횟수 한도는 그대로**(보상 총량은 무과금 광고 시청자와 같다 — 밸런스 영향 0, 시청 시간만 아낌).
4. **확률·가격을 숨기지 않는다.** 소환 확률은 이미 공개(rarities.json → 상점에 표시). 묶음은 '정가 대비 n%'를 실제 계산으로 보여 준다.
5. **한정은 정직하게.** '스타터 팩'(계정당 1회, 시작 7일)·'첫 구매 2배'(젬 팩마다 1회)만 한정. 가짜 타이머·매일 바뀌는 할인 압박은 없다.

## 3. 항해 패스(시즌 30일)
- 경험치: 일일 퀘스트 1개 = 10, 보스 첫 처치 = 2, 현상금 1판 = 5. 한 단계 = 50 → 하루 성실 플레이 약 1.5~2단계, 30일에 30단계(무과금이 완주할 수 있게).
- 무료 줄(30): 젬 30 ×10 · 소환권 1 ×5 · 지도 조각 2 ×5 · 현상금 티켓 ×5 · 30단계 '패스 깃발'(칭호, 꾸밈).
- 유료 줄(30): 젬 60 ×10 · 소환권 2 ×8 · 영웅 확정 카드 ×2 · 시즌 전용 배 스킨(꾸밈) ×1 · 지도 조각 5 ×5 · 30단계 전설 확정 소환 1(첫 전설 유예 meta.firstLegend는 그대로 지킴 — 유예 중이면 영웅으로).
- 유료 줄 합계 ≈ 젬 600 + 소환 16 + 영웅 2 + 스킨 → 소환 환산 약 36회(≈ 12,000원어치)를 9,900원에. 시즌 중간에 사도 지난 단계 보상을 다 받는다.

## 4. 세이브 권리 구조(entitlements) — 계약 제안(S1 승인 필요)
GameState에 선택 키 `entitlements`(없으면 무과금, 스키마 버전 올리지 않음):
```json
"entitlements": {
  "noAdsUntil": "2026-11-30T00:00:00Z",   // 구독 만료(영구면 "permanent")
  "speedUntil": "permanent",
  "offlineHours": 12,
  "starter": true,                         // 스타터 팩 샀음
  "firstBuy": ["gem_120", "gem_650"],     // 첫 구매 2배를 쓴 상품
  "gemSub": { "until": "2026-11-30T00:00:00Z", "lastClaim": "2026-11-02" },
  "pass": { "season": "s1", "premium": true, "xp": 420, "claimedFree": 8, "claimedPaid": 8 },
  "skins": ["golden_galleon"]
}
```
- 결제 확인은 어댑터(S5)가 스토어 영수증으로 하고, 엔진엔 명령 `GrantPurchase(sku, receiptId)`만 들어온다(같은 receiptId 두 번이면 무시 — 중복 지급 막기). 구독 갱신·만료도 어댑터가 `GrantPurchase`/`RevokeEntitlement`로.
- 엔진 쪽 읽는 곳: 광고 버튼(noAds면 `GrantAdReward`를 시청 없이 바로 — 하루 한도 그대로), 배속(speedUntil이면 BattleView.speed 2 — 순풍 TailwindSpeed와 겹치면 2 유지), 오프라인 상한(offlineHours), 월간 젬(접속 때 하루 한 번 `ClaimGemSub`), 패스(퀘스트·보스·현상금 → xp).
- 상품표 데이터는 새 표 `iap.json`(sku·가격 등급·효과·한정 조건) — 스토어 가격은 스토어가 정하고 표엔 등급만.
- 지금 있는 것과 잇기: 맛보기(meta.trials, review/trials)가 끝나면 '광고로 10분 더(ads tailwind·autoUpgrade) / 2배속 영구(#4)·선장 패키지(#5)' 안내.

## 6. 규정·표시
- 확률형 아이템 표시(소환 확률·천장 50회)는 상점·소환 화면에 이미 있다 — 패스·스타터의 '확정'은 확률 아님(명시).
- 미성년자 결제: 스토어 보호자 동의·결제 한도를 따른다. 상점에 '구매 내역·환불 안내'(스토어 정책 링크).
- 구독(광고 제거·2배속·월간 젬)은 해지 방법을 상점에 한 줄로.
- 가격 표시는 스토어가 준 현지 가격 문자열 그대로(환율 계산 안 함).
