# 스펙: 포탄·폭발 퀄리티 (사용자 직접 지시 2026-10-15)

- 사용자: "폭탄 퀄리티가 조잡하고, 캐릭터마다 폭탄 날아가는 게 너무 빠르고, 조잡하게 터지는 게 보기 싫다."
- 재료: Pirate Busters(같은 자체 IP, 무료) `png/weapons/<id>@2x.png`(무기 36종 + bomblet), `png/fx/impact/*@2x.png`(번쩍·별 폭발·충격파·불덩이 5단계·연기·물보라·불티·파편) → `tools/art/import_pb.py` → `assets/weapons/`, `assets/fx/pb/` (무손실 WebP, OWN).
  강습 계열 5명(crabby·davy·king·lobster·shark)은 PB에서 직접 날아가 때려 무기 그림이 없다 → 계열 발사체 그대로.

## 규칙
1. 발사체 = 선원별 무기 그림(부드럽게 축소, `pbFx.weaponScale`). 투척·물수제비·낙하는 비행 중 1.5바퀴 회전, 직선은 진행 방향을 보고 꼬리 잔상 3개.
   범위 계열(투척·수중, `projectiles.<계열>.single`)은 대상마다가 아니라 조준점에 한 발.
2. 비행 시간 = `fx_map projectiles.<계열>.flightMs`(투척 750 · 물수제비 650 · 수중 550 · 낙하 450 · 충격 400 · 관통 350 · 직사·강습 300ms).
   **도착 = 엔진 피해 틱 그대로**(엔진은 발사와 피해가 같은 틱). 렌더가 그만큼 먼저 띄우려고 `juice replay.lookaheadTicks` 2 → 16(0.8초) — 표시가 엔진보다 0.8초 뒤.
   엔진(battle) 값은 바꾸지 않는다. 포구 화염은 실제 발사 시각에(지연).
3. 폭발(`explosion_aoe` 이펙트) = PB 부품 단계: 번쩍(0~90ms) → 별 폭발(0~220) → 충격파 고리(50~330) → 불덩이 5단계 뜨거움→연기(60~560) → 연기 덩이 3개 퍼지며 오름(180~880) →
   파편 4·불티 6 포물선 → 바다면(y ≥ 96) 물보라(250~760). 길이 `pbFx.blastMs` 900. 크기 = 이펙트 폭 × `blastSize`(스킬·궁극기 배율 그대로 따라감).
4. 대량 폭발: 같은 자리(18도트)·같은 순간(90ms)이면 하나로 합쳐 1.2배씩(최대 1.8배), 동시 10개 상한.
5. PB 그림이 없으면(에셋 미등록·테스트) 기존 도트 시트·계열 그림으로 그린다.

## 검증
- `battle_scene_test`: 투척은 flightMs만큼 먼저 떠서 엔진 피해 틱에 도착, 직선 계열은 더 짧게(250~400ms).
- 부하 장면(sprite_perf_test) 래스터: 전 3.9ms → 후 3.3~3.8ms/프레임(합치기·상한 덕), 기록 비용 비슷.
- 비교: `docs/specs/render-bombs/sequence_s24.png`(전/후 0.1초 × 8장), `sequence_tablet.png`(태블릿 800×1280), `goldens_before_after.png`.
