# 기획: 바다 분위기 변화 — 시간대·날씨·지나가는 풍경

- 상태: 초안 (2026-10-15, S5, 사용자 결정 '지루함 해소 3종' ③)
- 한 줄: 같은 바다라도 **낮 → 노을 → 밤 → 새벽**이 돌고, 가끔 **비·안개·오로라**가 내리며, 뒤로 **섬·등대·고래**가 지나간다. 눈이 심심하지 않게.
- 성격: **보기만 바뀐다**(능력치·보상 없음) → 엔진·세이브·계약 변경 없음, **render 레인 단독**(+ 아트). 폭풍만 `platform-fun-sea-events.md`의 storm 이벤트와 연결.
- 피로 규칙 대응: 밤에도 적·숫자가 잘 보여야 한다(가독성 우선). 번쩍임 끄기 설정이면 번개 섬광 없음. 절전 모드면 날씨 파티클 ½·풍경 정지.

## 1. 시간대 순환
1. 렌더 시계(실제 경과 시간, 엔진 아님)로 **12분 한 바퀴**(`atmosphere.cycleSec` 720): 낮 6분 → 노을 1.5분 → 밤 3분 → 새벽 1.5분. 바뀔 때 20초 동안 서서히.
2. 해역 하늘 팔레트에 **색조 곱하기**: 노을(주황 +, 채도 +), 밤(남색, 밝기 ×0.55, 별 점 40개 반짝임), 새벽(분홍 엷게).
3. **가독성 규칙**: 밤에도 적·투사체·피해 숫자는 색조를 받지 않는다(배경 띠만). 적 외곽선 1px 밝게(밤만).
4. 기기 시계와 무관(현실 밤에 게임까지 어두우면 답답하다는 판단) — 열린 질문 1.

## 2. 날씨 (가끔)
| 날씨 | 언제 | 연출 | 해역 |
| --- | --- | --- | --- |
| 비 | 시간대마다 25% (렌더 난수, 시드 = 접속 시각) | 사선 빗줄기 도트 2px, 바다 물결 ↑, 하늘 회색 띠 | 산호·폭풍·심연 |
| 안개 | 새벽에 40% | 먼 바다 띠 반투명 흰 막 2겹, 천천히 흐름(적 위로는 안 덮음) | 빙하·유령 |
| 오로라 | 밤에 50% | 하늘 위쪽 초록·보라 띠 사인 물결 | 빙하 전용 |
| 폭풍 | 돌발 이벤트 storm 동안 | 비 + 번개 섬광(번쩍임 설정 따름) + 큰 파도 | 전 해역 |
| 화산재 | 화산해 상시 약하게 | 위에서 내려오는 회색·주황 점 | 화산 |

## 3. 지나가는 풍경 (시차 배경)
- 배경 3겹: 먼 하늘(고정) · **먼 바다(풍경, 0.2배 속도)** · 가까운 물결(1배).
- 풍경 목록(해역별 가중): 작은 섬(야자수) · 등대(밤엔 불빛 회전) · 고래(물 뿜기, 30초 등장) · 난파선 잔해 · 빙산(빙하) · 화산섬(화산) · 유령선 그림자(유령).
- 간격 40~90초에 하나, 화면을 20~40초에 걸쳐 오른쪽 → 왼쪽. 동시에 최대 2개.
- 배치 v2의 **늘어난 하늘·깊은 바다 칸**(전장 폭 채우기 — 태블릿에서 특히 넓다)이 풍경 자리 — 게임 영역(320×180) 밖에도 그린다.

## 5. 아트 (art)
- 풍경 그림 9종(먼 바다 크기, 2~4색 실루엣 중심 — 시차 배경이라 디테일 적게), 별·빗줄기·화산재는 코드로(그림 없음), 오로라는 코드 그라데이션 띠.
- 등대 불빛·고래 물 뿜기만 2~4프레임.

## 6. 성능·설정
- 성능: 날씨 파티클 최대 120개, 풍경 2개 — 부하 장면 p95 ≤ 16.7ms 유지(렌더 성능 기준). 저사양 1대 확인.
- 설정: 기존 '번쩍임 끄기' → 번개 없음, '절전 모드' → 파티클 ½, 풍경 정지(그림은 보임), 색조 전환 즉시.
- **태블릿 800×1280**: 전장이 폭 전체를 채우므로 늘어난 하늘이 넓다 — 별·오로라·풍경이 그 칸을 채워 빈 띠처럼 보이지 않게(배치 v2 render 몫과 같이).

## 7. 수용 기준 (render 골든 + 위젯 테스트)
1. 골든 4장: 같은 장면을 낮·노을·밤·새벽 시각으로 — 밤에도 적·숫자 색이 낮과 같음(픽셀 비교로 적 스프라이트 영역 동일).
2. 렌더 시계 720초 진행 → 단계 순서·전환 20초 서서히(중간 프레임 색 보간 확인).
3. 번쩍임 끔 → 폭풍 중 화면 섬광 0프레임.
4. 절전 → 파티클 수 ½, 풍경 위치 고정.
5. 결정론 필요 없음(엔진 밖) — 단, 골든은 시드·시각 고정으로 재현.
6. 성능: 비 + 풍경 2개 + 피버 동시 부하 장면 p95 ≤ 16.7ms.
