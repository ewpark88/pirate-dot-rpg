# T4-B 탑다운 선원 균형 — 렌더 레인 측정 (S3)

- 기준: S5 review/topdown-t4-2 8fe4db2(엔진 옆모습 삭제·선체 캡슐 새 크기·topRange) 위, `balance crews`(레벨 15·30·45·60·75, ±10%).
- 적용 파일: `skills_top.json`(이 폴더) — `packages/game_data/tables/skills.json`을 이것으로 바꾸면 된다(families만 바뀜).
- 결과: 계열 평균이 다섯 레벨 모두 ±10% 안(최대 강습 1.078 @75). 6명 조합 상위 1% ×1.064(한도 1.3).
- 남은 실패: 레벨 60·75에서 **같은 계열 안 선원끼리** 벌어짐(전설 능력·선원 보정 — 예: bara·pumpum·davy 1.3, kraki·nar 0.74~0.87). 이 벌어짐은 바꾸기 전 기준에도 있었다(davy 1.36, nar 0.55 @15). 계열 값이 아니라 legends·crews reachBonus 쪽이라 S2·S5 결정 필요.
