# 스펙: M3 메타 화면 — 다음 목표 막대 · 보물상자 · 순풍 · 일일 퀘스트·출석·도감 · 튜토리얼

- 상태: 승인됨 (2026-10-14, S1) · 레인: ui · 설계서 절: 4.5 · 4.6 · 4.9 · 4.12
- 필요한 계약·경제 변경: `docs/contracts/requests/ui-m3-meta.md` (S1 계약·세이브, S2 규칙)

## 목적
- 단순한가: 새 탭 없이(탭 4개 고정) 전장 위 아이콘 2개(상자·순풍)와 퀘스트 아이콘 1개, 상단 목표 막대 1줄만 더한다.
- 피로가 없는가: 팝업을 늘리지 않는다(퀘스트·출석은 아이콘 → 하단 시트). 빨간 점은 받을 보상이 있을 때만. 놓치면 사라지는 보상 없음(출석은 이어서).
- 공정한가: 광고 버튼은 이득을 숫자로(“×5 · 12.4K”), 광고 포트가 없거나 로드 안 되면 숨긴다.

## 규칙
1. 화면은 `GameState`만 구독한다(이벤트를 화면 상태로 쓰지 않는다). 그래서 상자·퀘스트 완료·튜토리얼 단계는 **상태에 있어야 한다** → 요청서.
2. 버튼은 `Command`만: `TapChest`, `GrantAdReward(placement)`(광고 콜백 뒤에만), `ClaimDaily`, `ClaimAttendance`, 튜토리얼은 새 명령(요청서).
3. 금액·진척·조건은 경제 함수로만 구한다. UI에 식을 두지 않는다.
4. 광고 버튼은 `AdsPort`가 앱에 연결되기 전까지 숨긴다. 이번 범위의 광고 버튼은 자리와 숨김 규칙만 만든다.
5. 문구는 `parts/ui.*.arb`(ko/en). 튜토리얼 문구 키는 `uiTut…`(레인 접두어 규칙 우선, 설계서의 `tut.*`는 의미 표기 — S1 결정).

## 화면
### ① 다음 목표 막대 (4.5, 4.12 ‘목표 막대 약 3%’)
- HUD 아래 한 줄: 가장 가까운 목표 하나의 문구 + 진행 막대. 예) ‘범선 승급까지 스테이지 4’, ‘대포 Lv50 도약까지 3’, ‘도감 보너스까지 1명’, ‘환생 가능까지 스테이지 3’.
- 목표 고르기·진행률은 경제 `nextGoal(state, tables)`(요청). UI는 종류별 문구만.

### ② 보물상자 (4.6)
- 상태에 떠 있는 상자가 있으면(요청: `GameState.chest`) 전장 위 그 위치(논리 좌표 → 전장 상자 비율)에 탭 영역 + 가라앉기까지 남은 시간 링.
- 탭 → `TapChest`. 기본 보상 금액을 상자 위에 작게(`chestReward` 요청). 광고 ×5 · 젬 버튼은 광고 포트 전까지 숨김.
- 하루 한도 다 쓰면(`ads.json` chest.dailyLimit, 경제 판정) 상자 자체가 안 뜬다(경제 규칙).

### ③ 순풍 버프 (4.6)
- HUD 오른쪽 돛 아이콘: `buffs.tailwindUntil`이 지금 이후면 남은 시간(mm:ss, 1시간 넘으면 h:mm) + ‘×2’. 없으면 흐린 아이콘.
- 누르면 광고 버튼(‘광고 보고 30분 ×2’, 남은 하루 횟수) — 광고 포트 전까지 숨김. 그래서 이번 범위는 **표시만**.
- 남은 시간은 `tailwindRemaining(state, now)`(요청, 최대 누적 4시간 반영) 또는 `tailwindUntil − now`를 0 이하에서 자른 값.

### ④ 일일 퀘스트·출석 (4.5 매일, 4.9)
- 전장 위 왼쪽 아이콘 1개(퀘스트·출석 겸용, 받을 것이 있으면 빨간 점) → 하단 시트(HUD 안 가림), 위 칸 퀘스트 4줄, 아래 칸 출석 7칸.
- 퀘스트: 이름·진행 `n/목표`·완료 표시. 4개 모두 완료면 **받기**(젬 40) → `ClaimDaily`. 이미 받았으면 ‘받음’.
- 출석: 7칸, 오늘 칸 강조, 받은 칸 체크, 7일차 ‘영웅 이상 소환권’. 오늘 아직이면 **받기** → `ClaimAttendance`. 하루 빠져도 이어서(리셋 없음).
- 퀘스트 목록·진행·완료·받았는지, 출석 칸 보상·오늘 받을 수 있는지는 경제 함수(요청).

### ⑤ 도감 (4.5 수 주)
- 선원 탭 위 줄: ‘도감 n/40 · 공격력 +X%’ + 다음 보너스까지 m명(`collectionBonus` 요청). 도감은 선원 격자 그대로(미보유 흐림)라 새 화면은 만들지 않는다.

### ⑥ 튜토리얼 (4.12 표, 3분, 언제든 건너뛰기)
- 상태의 튜토리얼 단계(요청: `GameState.tutorialStep`, 끝나면 null)에 따라 안내 말풍선 1개 + 손가락(가리킬 위젯 키), 오른쪽 위 ‘건너뛰기’.
  | 단계 | 문구 | 가리키는 것 |
  | --- | --- | --- |
  | 1 | 바다 괴물이 몰려와요! 해적선이 알아서 싸워요. | 전장 |
  | 2 | 대포를 강화해 보세요. | 배 탭 → 대포 강화 버튼 |
  | 3 | 보스가 강해요. 배를 더 강화해 볼까요? | 대포 강화 → 보스 도전 |
  | 4 | 젬으로 선원을 불러 보세요. | 소환 탭 → 10회(무료) |
  | 5 | 같은 선원 카드를 합치면 강해져요. | 선원 탭 → 일괄 합치기 |
  | 6 | 이제 배가 알아서 싸워요. 앱을 꺼도 골드가 쌓여요! | 목표 막대 |
- 단계 넘김 조건(대포 Lv3, 보스 일부러 실패, 강화 2번 후 도전, 소환 결과 닫기, 일괄 합치기 1번)은 **코어가 판정**하고 상태를 바꾼다. UI는 단계만 보고 그린다. 예외: ‘소환 결과 닫기’는 UI 동작이라 `TutorialAck` 같은 명령이 필요(요청).
- 튜토리얼 중에는 광고 제안을 숨긴다(4.6). 운영자 패널에 ‘튜토리얼 단계 N부터’(요청: `OpSetTutorial`).

## 수용 기준 (Given / When / Then) — 각각 위젯 테스트
1. Given 경제 `nextGoal`이 (범선, 남은 스테이지 4)를 주는 상태 Then 목표 막대 문구와 막대가 보인다.
2. Given 상자가 떠 있는 상태 Then 전장 위 탭 영역이 있고 누르면 `TapChest`. 상자가 없으면 탭 영역 없음.
3. Given 광고 포트 없음 Then 상자·순풍의 광고 버튼이 없다.
4. Given `tailwindUntil` = 지금 + 12분 30초 Then ‘12:30’과 ‘×2’. 지난 시각이면 흐린 아이콘·시간 없음.
5. Given 퀘스트 3/4 완료 Then 아이콘에 빨간 점 없음·받기 비활성 / 4/4 미수령 Then 빨간 점·받기 → `ClaimDaily`.
6. Given 출석 오늘 미수령 Then 빨간 점·받기 → `ClaimAttendance` / 수령 후 Then 오늘 칸 체크·받기 없음.
7. Given 도감 4/40 Then ‘공격력 +0%’ 와 ‘다음 보너스까지 1명’.
8. Given 튜토리얼 2단계 Then 말풍선 문구와 손가락이 배 탭·대포 버튼을 가리킨다. ‘건너뛰기’ → 튜토리얼 건너뛰기 명령.
9. Given 튜토리얼 중 Then 광고 제안 자리가 숨는다.
10. 영어 골든 3장: 목표 막대+상자+순풍 HUD, 퀘스트·출석 시트, 튜토리얼 2단계.
