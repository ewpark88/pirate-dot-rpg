- 근거: 사용자 실기기(Galaxy S24, 1080×2340, dpr 2.8125 → 384×832dp) 화면 `layout-v2/device_*.png`.
- 사용자: "버튼이 가려지고 게임 화면도 버튼 위치 때문에 보이지 않는다. 도트 게임이어도 보기 편한 디자인이어야 한다."
  **1단계 = 배치(이 문서)**, 2단계 = 디자인 퀄리티(사용자와 계획 논의 후).

## 새 화면 구조 (위 → 아래)
1. **상단 바** (높이 40dp, 전장 밖, ui): 왼쪽 골드·젬(도트 아이콘 + 숫자), 오른쪽 퀘스트·설정 아이콘 버튼(그림 24~28dp, 누르는 영역 48dp). 순풍이 켜졌으면 남은 시간 칩.
   → 캔버스 HUD의 골드는 지운다(중복). 캔버스에는 **스테이지·보스 체력·보스 타이머**만.
2. **전장** (render): 폭 전체를 채운다. 정수배 k = floor(물리 폭 / 320)로 그리고, **남는 좌우·위아래는 배경(하늘 띠·바다 띠·물결)을 늘려 채운다** — 빈 띠·잘림 없음. 게임 영역(320×180)은 가운데.
   높이 = 화면의 약 38~42%. 늘어난 높이는 하늘(위)과 깊은 바다(아래)로.
   **전장 안에는 누르는 버튼을 두지 않는다**(보물상자 탭은 예외 — 게임 오브젝트).
3. **선원 줄** (render 그림 + ui 버튼, 전장 바로 아래 한 줄, 높이 약 56dp): 왼쪽 선원 슬롯 6칸(빈 칸은 빈 슬롯 테두리), **오른쪽 끝 궁극기 버튼(게이지 포함)**, 보스 실패 중이면 그 옆 보스 도전 버튼.
4. **목표 띠** (지금 것 유지).
5. **탭 내용** (스크롤).
6. **탭 바**.
- 광고 '30분 ×2'는 상단 바 순풍 칩 옆의 작은 광고 아이콘 버튼으로(그림 24dp). 항해 탭 순풍 줄에도 같은 버튼.

## 탭 내용 규칙
- 글자: 본문 최소 14sp 상당(도트 폰트 정수배 중 가장 가까운 것), 제목 16~18.
- 선원 탭: 384dp에서 **4열**. 이름은 짧은 이름만 한 줄(별명 'the …'·'딱총새우' 같은 앞말은 상세 창에서). 레벨·카드 수는 초상 위 작은 도트 배지.
- 항해·소환 탭: 내용을 카드(PixelFrame) 단위로 묶고 세로 공간을 쓴다 — 소환 버튼 크게(높이 64dp), 확률은 등급 색 막대.
- 창·시트: 모든 버튼은 PixelButton(글자 링크 금지). 퀘스트 체크박스는 check/check_empty 도트 아이콘, 보상 버튼은 젬 아이콘 + 숫자.

## 나눔
- **render(S3)**: 전장 채우기(배경 확장·정수배·가운데 정렬), 캔버스 HUD에서 골드 제거·보스 타이머 캔버스로, 선원 줄 6칸(빈 슬롯) + 궁극기·보스 도전 자리 비워 두기(좌표를 layout.dart 상수로 공개).
- **ui(S4)**: 상단 바, 전장 위 오버레이 삭제 → 상단 바·선원 줄 오른쪽으로 이동, 탭 내용 규칙, 창·시트 도트화, 글자 크기.
- 둘 다: **384×832 dp, dpr 2.8125(S24)** 와 360×640·411×891에서 골든 + 넘침 테스트. 비교는 실기기 캡처와 나란히.
- 계약 변경 없음(BattleView 그대로). render↔ui 좌표 약속은 `render/layout.dart` 상수.
