# 스펙: 초반 가이드 v2 — '어르신도 쉽게' (S4, 사용자 피드백 #3)

- 출처: 사용자 폰 20분 플레이 피드백 #3(2026-10-17) — "노인도 이해하는 친절한 설명, 지금 디자인이 마음에 안 든다". S1 승인 뒤 구현.
- 레인: UI(S4)만. **계약 변경 없음** — 코어 튜토리얼 단계(`tutorialStep` 1~6·TutorialAck·SkipTutorial)와
  세이브 안내 기록(`Settings.hints`·`MarkHint`)을 그대로 쓴다. '다시 보기'만 선택 요청(아래 6).

## 1. 지금 무엇이 문제인가
| 지금 | 문제 |
| --- | --- |
| 전장과 패널 사이 한 줄 말풍선(14sp), 건너뛰기·확인 버튼이 같은 줄 | 글씨가 작고, 줄 하나에 버튼 2개가 붙어 무엇을 누를지 헷갈린다 |
| '대포를 강화해 보세요.'처럼 '무엇'만 있음 | **왜** 해야 하는지 없음 → 의미 없이 따라 누름 |
| 가리킴 = 금색 네모 + 작은 손(16도트), 움직임 없음 | 손가락이 잘 안 보이고, 화면 어디를 봐야 하는지 모름 |
| 첫 6단계 뒤에는 안내 없음 | 피버·보스·화물칸·합치기·환생을 처음 만나도 설명이 없음 |

## 2. 원칙 (모든 안내 카드 공통)
1. **큰 글씨**: 제목 22sp, 본문 18sp, 버튼 글자 18sp·높이 56dp 이상. OS 글자 크기 1.3배에서도 잘리지 않는다(줄바꿈으로 늘어남).
2. **한 번에 한 가지**: 화면에 안내 카드는 늘 하나. 나머지는 줄 서서 기다린다(기존 알림 우선순위 아래 — 7).
3. **손가락으로 가리킴**: 누를 곳 둘레만 밝고 나머지는 살짝 어둡게(스포트라이트, 검정 45%) + 큰 손가락(36dp)이 0.8초 주기로 톡톡 누르는 움직임.
   '동작 줄이기'(OS)·번쩍임 끔에서는 손가락이 움직이지 않는다.
4. **왜 한 줄**: 모든 카드 = 제목(무엇) + 왜(한 줄, '그러면 ~해요') + 버튼. 3줄을 넘지 않는다.
5. **누를 곳만 누를 수 있게 하지 않는다**: 어두운 곳을 눌러도 막지 않는다(갇힌 느낌 금지). 대신 카드는 그 동작을 할 때까지 남는다.
6. **건너뛰기는 작게, 하지만 늘 있다**: 카드 오른쪽 위 '건너뛰기' 글자 버튼(48dp 누름 영역). 누르면 '안내를 끌까요? [끄기] [계속 보기]' 확인 한 번.

## 3. 생김새
```
┌──────────────────────────────┐  ← 상단 바·게이지 (그대로)
│ ░░░░░░░ 전장(어둡게 45%) ░░░░░ │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ ┌──────────────────────────┐ │  ← 안내 카드: 전장 아래쪽, 도크 바로 위
│ │ (아이콘)  대포를 강화해요     │ │     흰 카드·금 테두리 3dp·그림자, 가로 = 화면 - 32dp(최대 440dp)
│ │ 대포가 세지면 괴물을 더 빨리 │ │     본문 18sp, 2줄까지
│ │ 잡고 골드를 더 벌어요.       │ │
│ │                [건너뛰기]   │ │
│ └──────────────────────────┘ │
├──────────────────────────────┤
│  [항해] [ 배 ]👆 [선원] [소환] │  ← 누를 곳만 밝게 + 손가락 톡톡
└──────────────────────────────┘
```
- 카드 왼쪽 아이콘은 그 시스템 그림(배·선원·젬·피버 불꽃·해골·상자·지도) — 기존 SkinIcon·UiSprites 재사용, 새 그림 없음.
- 카드 위치: 누를 곳이 아래(도크·패널)면 카드는 전장 아래쪽, 누를 곳이 위(보스 도전·게이지)면 전장 위쪽 게이지 바로 아래. 누를 곳을 가리지 않는다.
- 확인만 하는 카드(설명뿐)는 큰 버튼 하나 '알겠어요'(56dp, 가로 꽉).
- 태블릿: 카드 최대 440dp 가운데, 글씨 배율은 기존 태블릿 UI 배율(최대 1.4)을 따른다.

## 4. 첫 6단계 (코어 tutorialStep 그대로, 문구·가리킴만 새로)
| 단계 | 제목(무엇) | 왜(한 줄) | 가리킴 | 끝나는 조건 |
| --- | --- | --- | --- | --- |
| 1 | 배가 알아서 싸워요 | 가만히 있어도 괴물을 잡고 골드를 모아요. | 없음(전장 밝게) | [알겠어요] |
| 2 | 배를 강화해요 | 대포가 세지면 괴물을 더 빨리 잡고 골드를 더 벌어요. | 도크 빠른 강화 → (배 탭이 열려 있으면) 대포 강화 버튼 | 코어(강화 1회) |
| 3 | 보스를 이겨요 | 보스를 쓰러뜨리면 다음 바다로 가요. 지면 배를 더 강화하고 다시! | 보스 도전 버튼(파밍 중) / 대포 강화 | 코어 |
| 4 | 선원을 불러요 | 선원이 함께 싸우면 훨씬 강해져요. 젬으로 10명을 불러요. | 소환 탭 → 10회 소환 | 코어(소환 결과 닫기) |
| 5 | 같은 선원을 합쳐요 | 같은 카드를 모으면 별이 오르고 공격력이 커져요. | 선원 탭 → 일괄 합치기 | 코어 |
| 6 | 이제 자유롭게! | 앱을 꺼도 골드가 쌓여요. 위쪽 목표를 따라가면 돼요. | 목표 막대 | [알겠어요] |

## 5. 처음 만나는 시스템 안내 (튜토리얼 뒤, 각 1회)
세이브 `Settings.hints`에 id를 남겨(MarkHint) 앱을 다시 켜도 다시 안 뜬다. 튜토리얼이 끝난(또는 건너뛴) 뒤에만 뜬다.
| id | 언제(첫 번째) | 제목 | 왜 | 가리킴 |
| --- | --- | --- | --- | --- |
| guide.fever | FeverStarted | 피버! | 처치가 쌓이면 10초 동안 모두 강해지고 첫 일격이 화면을 쓸어요. | 피버 게이지 |
| guide.boss | 처음 보스전 시작 | 보스전 | 제한 시간 안에 쓰러뜨려요. 아래 브레이크 막대가 차면 보스가 쓰러져 3배 피해! | 보스 시간·브레이크 막대 |
| guide.cargo | 화물칸 80% 이상 | 화물칸이 차요 | 가득 차면 골드를 더 못 모아요. 배 탭에서 화물칸을 키워요. | 상단 골드 막대 → 배 탭 |
| guide.merge | 처음 합치기 가능 | 합칠 수 있어요 | 같은 선원이 모였어요. 합치면 더 강해져요. | 선원 탭(빨간 점) |
| guide.upgradeCrew | 처음 선원 레벨업 가능 | 선원 레벨업 | 레벨이 오르면 그 선원의 공격력이 올라요. | 선원 탭 |
| guide.rebirth | 처음 환생 가능 | 환생 | 처음부터 다시 가지만 영구 보너스로 훨씬 빨리 달려요. | 항해 탭 환생 카드 |
| guide.summon | 튜토리얼 뒤 처음 젬 ≥ 10연 비용 | 선원을 더 불러요 | 젬이 모였어요. 새 선원이 나올 수 있어요. | 소환 탭 |
- 기존 1회 말풍선(boss.bubble·rebirth.bubble·'탭!' 손가락)은 이 카드로 합친다 — 같은 내용을 두 번 보이지 않는다.
- 보스전·피버 중에는 '설명만' 카드라 전장을 어둡게 하지 않는다(싸움을 가리지 않게). 3초 뒤 저절로 작아져 위쪽 한 줄 알약으로 남고, 누르면 다시 펼침.

## 6. 설정
- '안내 다시 보기' 버튼: 첫 6단계는 다시 하지 않고, 5의 시스템 안내를 다시 켠다.
  → `Settings.hints`에서 guide.* 를 지우는 명령이 필요 — **선택 요청**(S2·S5): `ClearHints(prefix)`. 승인 전엔 버튼을 두지 않는다.

## 7. 다른 알림과의 순서 (기존 규칙에 끼우기)
- 한 번에 카드 하나. 순서: 오프라인 보상 창 > 소환 결과·승급 연출 > **가이드 카드** > 보스 실패 안내 > 알약(현상금 > 도전 > 돌발 > 화물칸 > 환생) > 토스트.
- 가이드 카드가 떠 있으면 알약·말풍선은 기다린다(사라지면 이어서). 도감 첫 처치 토스트는 토스트 줄에.

## 8. 수용 기준 (테스트 1개 이상씩)
1. 단계 1~6마다 카드 제목·왜·가리킴이 표대로 (위젯 테스트, ko·en).
2. 글씨: 제목 ≥ 22, 본문 ≥ 18, 버튼 높이 ≥ 56dp. OS 글자 1.3배 + 360×640에서 넘침 없음.
3. 스포트라이트 구멍이 가리킨 위젯 사각형을 포함하고, 어두운 곳을 눌러도 아래 위젯이 눌린다.
4. 5의 안내는 조건이 처음 맞을 때 한 번, MarkHint를 보내고, hints에 있으면 안 뜬다. 튜토리얼 중엔 안 뜬다.
5. 동시에 카드 둘 없음(조건 둘이 같이 맞으면 줄 서기).
6. 동작 줄이기·번쩍임 끔에서 손가락 고정.
7. 골든: 2단계·guide.boss를 4기기(360·S24·411·태블릿) ko + en 1장씩.

## 9. S1 결정 (2026-10-17 승인)
- (a) **첫 6단계는 밝은 곳 밖 누름을 막는다**(엉뚱한 곳을 눌러 길을 잃는 것이 가장 흔한 이탈). 어두운 곳을 누르면 손가락이 한 번 더 크게 톡톡 + '여기를 눌러요'.
  처음 만나는 시스템 카드는 막지 않는다(전투 중 3초 뒤 알약 접힘 그대로). → 2-5는 튜토리얼 밖 카드에만 해당.
- (b) 5에 3개 추가 → 10개: guide.chest(보물상자 첫 등장 — '눌러서 열어요, 광고를 보면 더 좋은 것'),
  guide.newCrew(환영 선원 bones, 첫 희귀 — '새 동료! 5연사'), guide.sail(환생 뒤 '출항!' 버튼 — S5 sail-hold, TutorialSpot 'sail.start'). 현상금은 뺀다(나중).
- (c) '안내 다시 보기'를 지금 넣는다: ClearHints(prefix)는 S2가 구현(economy_system MarkHint 옆). 설정 버튼 자리는 S4가 먼저 만들고, 명령이 들어오면 연결.
- 글씨·56dp 버튼은 4기기 골든으로 넘침 없음을 확인한다.
