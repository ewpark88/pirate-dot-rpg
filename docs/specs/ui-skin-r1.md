- 상태: **시안 — 사용자 승인 대기** (S1이 보여 줌). 2026-10-15.
- 사용자: "스킨이 너무 올드하고 허접하다. 세련되고 더 아기자기하게." → 1차 목표: 첫눈에 '요즘 귀여운 모바일 게임'.

- 비용: 0원. Flutter 코드로 그려 골든 방식으로 찍었다(이미지 생성·유료 도구 없음). 글꼴은 OFL만.

## 2. 모양
- 둥근 모서리: 카드 16dp, 버튼 14dp, 알약(칩·목표 띠) = 높이의 절반, 아이콘 뱃지 = 원.
- 버튼: 위가 밝은 그라데이션 + **아래 4dp 진한 테두리**(통통한 느낌) + 흰 1.5dp 안쪽 테두리. 누르면 아래 테두리만큼 내려앉고 95%로 줄었다가 통 튀어 돌아온다(easeOutBack 160ms).
- 카드: 흰/크림 판 + 부드러운 그림자, 테두리 선 없음.
- 아이콘 뱃지: 흰 원(44dp) 안에 그림 62%, 빨간 점은 오른쪽 위.
- 진행 막대: 둥근 알약, 채움은 같은 색 밝기 그라데이션.
- 탭 바: 화면 아래 떠 있는 흰 둥근 판(22dp), 고른 탭은 하늘색 알약 + 진한 파랑 글자.
- 전장: 도트 그대로, 둥근 창(18dp)으로 잘라 붙인다.

## 3. 글꼴 후보 (모두 OFL 1.1, Google Fonts 저장소 원문 확인)
| 글꼴 | 느낌 | 숫자·영문 | 크기(ttf) | 판단 |
| --- | --- | --- | --- | --- |
| **Jua** | 둥글고 굵음, 귀여움 | 또렷함 | 2.1MB | **추천** — 제목·숫자·버튼·본문 하나로 |
| Gowun Dodum | 부드럽고 단정 | 가늘어 작은 숫자가 약함 | 7.2MB | 본문용으로는 좋으나 무겁고 덜 귀여움 |
| Dongle | 아주 귀여움 | 글자가 작아 보여 크기를 키워야 함 | 4.5MB | 제목 장식용 정도 |
| Gaegu | 손글씨 | 숫자가 흔들려 큰 수 읽기 어려움 | 3.0MB | 비추천 |
- **주의(시안에서 발견)**: Jua·Gaegu에는 가운뎃점 ‘·’와 곱셈 ‘×’ 글리프가 없다(네모로 나옴). Jua를 쓰면 `fontFamilyFallback`으로 그 글자만 대체 글꼴(Gowun Dodum 또는 숫자 기호만 담은 작은 OFL 글꼴)에서 가져와야 한다 — 시안은 Gowun Dodum으로 대체해 그렸다.
- 원문: `github.com/google/fonts/ofl/<이름>/OFL.txt` (Copyright The Jua Project Authors 2018 등). 들일 때 OFL 원문을 assets에 같이 넣는다(Galmuri 때와 같은 방식).
- 크기: 본문 16sp, 작은 설명 14sp, 제목 19~20sp, 큰 숫자 22sp+. 도트 정수배 규칙은 버린다(매끈한 글꼴).

## 4. 선원 그림 = Pirate Busters 카드
- 선원 탭 목록·선원 상세·소환 결과: PB 카드(등급 back → 캐릭터 → 등급 front)에 글자(별 리본·이름·레벨·카드 수)는 UI가 그린다. 레이아웃은 PB `cards.json`(그림 창 12,12–228,250, 이름 120,292, 리본 258).
- 미보유: 캐릭터를 어두운 실루엣으로, 테두리·별은 그대로.
- 도트 초상은 전장 선원 줄에만.
- 그림 들이기(`assets/crew_art/`·`assets/ui/cards/`)는 S3, pubspec 등록은 S1, 화면은 S4.

## 5. 2단계 (승인 후)
- `lib/ui/skin/` 새 컴포넌트(SkinCard·SkinButton·SkinPill·SkinIconBadge·SkinBar·SkinTabBar·SkinSheet·SkinDialog)로 PixelFrame/PixelButton… 을 바꾼다. 화면 구조(layout v2)는 그대로.
- 애니메이션: 창 열림(0.9→1 스케일 + 페이드, easeOutBack), 탭 전환 슬라이드, 버튼 눌림, 보상 획득 반짝임(card_sparkle·card_shine 재사용).
- 골든 전부 다시 찍고 S24 비교.
