# 기획: 바다 도감 v2 — 몬스터·보스 다양화 (S5 리드)

- 상태: **초안(2026-10-16)** → S1 → 사용자 확인 · 담당: 엔진 S5 · 수치 S2 · 그림(무료 생성기·PB 재료) S3 · 도감 UI S4
- 사용자(S1 중계): "몬스터 종류를 더 다양하게, 보스도 더 다양하게 — 항상 똑같은 보스만 나온다. 문어·오징어 괴물·고래 괴물·레비아탄·포세이돈·괴물 뱀·바다 악어·아메바 같은 다양한 종류."
- 지금(2026-10-16): 해역 6(50스테이지씩) × 잡몹 4~5종. 보스는 **보통 스테이지 전부 enemy_ship**, 25에 중간 보스 1, 50에 해역 보스 1 → 한 해역 50번 중 48번이 같은 해적선.

## 목적
- 시원한가: 스테이지 끝마다 '이번엔 뭐가 나오나' — 보스 그림·움직임이 매번 다르다. 10단위 '대보스'는 화면을 꽉 채운다.
- 단순한가: 조작 그대로. 보스 이름 띠 + 약점 아이콘만.
- 공정한가: 보스 HP·공격 곡선은 그대로(S2) — 다양성은 '그림·패턴', 세기는 스테이지.

## 2. 새 보스 패턴 2 (보스 행동 v2 재사용 + 추가)
- 기존: 탄막(volley)·돌진(charge)·소환(summon)·장판(blast)·보호막·용암·촉수.
- **먹물(ink)**: 예고 0.6초 → 화면 일부(배 앞 원)에 먹물 2.5초 — 그 안의 적은 **조준되지 않는다**(선원이 못 봄). 문어·크라켄·대왕오징어.
- **삼키기(swallow)**: 예고 0.8초(입 벌림 빨간 원) → 원 안 잡몹을 삼켜 보스 HP 회복(마리당 n%) — 선원이 그 전에 잡으면 막는다. 바다 악어·괴물 고래.
- **분열(split)**: HP 50%·25%에서 작은 몸 2개로 갈라짐(각자 남은 HP의 일부, 둘 다 잡아야 격파). 아메바·슬라임.
- 엔진: BossPatternDef type 'ink'|'swallow'(+ 보스 `splitAt` [0.5, 0.25]), 이벤트 BossPatternShown 그대로(kind 추가) + InkCloud(x, y, radius, ticks).

## 4. 엔진 (S5)
1. regions.json `bosses` 추가 + 해역 `bossRotation`[4] · `wallBoss` · `wallEvery` 10 — `bossAt(stage)`가 순환·벽을 고른다(없으면 지금처럼 enemy_ship).
2. 패턴 ink·swallow, 보스 splitAt(분열 시 BossSplit 이벤트 + 작은 보스 둘, bossActive는 둘 다 죽을 때까지).
3. 잡몹 role 'bomber'·'swarm'(자폭은 접촉 시 hurtShip(cap × 2) 후 제거·처치 보상 없음 / 잡으면 반경 피해, 떼는 count × n·HP ÷ n).
4. 결정론·표 키 없으면 지금 그대로.

## 5. 도감 (S4)
- 항해 탭 '도감': 본 보스·적 실루엣 → 처음 잡으면 색이 채워짐 + 이름·한 줄. 모으는 재미(보상은 2차).

## 수용 기준
1. 같은 해역 연속 10스테이지에서 보스가 4종 이상 나온다(테스트), 10단위는 대보스.
2. 새 패턴 ink(조준 제외)·swallow(회복·막기)·split(둘 다 잡아야) 단위 테스트.
3. bomber·swarm 단위 테스트, 파 총량(HP·골드)은 지금 몫 그대로(진행 불변).
4. 표 키 없으면 지금 결과 그대로. 렌더 골든(보스 7종 × 해역 1장, S3).
