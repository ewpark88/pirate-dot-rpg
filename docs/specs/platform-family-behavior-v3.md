# 기획: 계열 행동 v3 — 계열마다 눈으로 바로 구분되는 행동 (S5 리드)

- 상태: **초안(2026-10-16)** → S1 → 사용자 확인 · 담당: 엔진 S5 · 수치·균형 S2 · 연출 S3 · 카드·상세 S4
- 사용자(S1 중계): "캐릭터 간 폭탄 공격 특성이 별로 차이 안 나고 구분도 안 된다. 폭탄 이미지 말고는 크게 차이가 없다." · "강습 계열 캐릭터들은 본인 자신이 폭탄이 되어, 쏠 때 본인이 나가서 몬스터를 잡고 돌아오고 강력한 공격력을 지닌다. 대신 쿨타임이 길고 … 이런 식으로 계열마다 특성을 살려라." · 추가: "새 계열 3개(원형 탄막·집속탄·레이저)를 적당한 캐릭터에게."
- 지금: 선원 개성 v2로 조준·연사·범위·탄 비행은 선원마다 다르지만, **그림이 거의 같은 '탄 하나가 날아가 펑'**이라 계열이 눈으로 안 갈린다.

## 목적 (설계서 1장)
- 시원한가: 계열마다 한눈에 다른 '쇼' — 선원이 직접 날아가 꽂힘, 하늘 높이 떴다 쾅, 다다다 기관포, 줄 달린 작살, 물수제비 통통, 물밑 그림자 → 솟구침, 급강하 폭격, 퍼지는 파동, 사방 링 탄막, 터지며 흩어지는 자탄, 화면을 가르는 레이저.
- 단순한가: 조작 없음(자동). 카드에 계열 아이콘 하나 + 한 줄.
- 공정한가: 계열 사이 '쿨·한 방 크기' 차이는 크게(사용자: 강습 쿨 길고 한 방 큼), **DPS는 같은 등급 ±10%**(S2 balance). 계열 차이는 '어떻게', 등급 차이는 '얼마나'.

## 1. 계열 11개 행동 표

- 간격 배율·한 발 크기는 '같은 DPS' 출발값(S2가 balance crews로 계열 power 재적합). 선원 개성 v2(조준·연사·특징)는 그대로 위에 얹는다.
- 등급별 성장(신규 3계열): 원형 탄막 발 수 일반 8 → 고급 10 → 희귀 12 → 전설 16 → 신화 24 · 집속탄 자탄 4 → 5 → 6 → 8 → 12 · 레이저 관통 1 → 2 → 3 → 5 → **무제한(화면 끝까지)**.

### 재배정 (겹치는 선원 우선, 그림·이름 맞춤)
- **puffer**(가시 복어 → 사방 가시) · **uni**(성게 → 사방 가시): 원형 탄막. 둘 다 '가시 뭉치·기뢰'로 투척·수중과 겹쳤다.
- **volke**(화산탄 → 파편 산개) · **starry**(불꽃 별 → 작은 별 터짐): 집속탄. 둘 다 투척 '센 놈에게 한 방'으로 겹쳤다.
- **lamp**(등불 → 빛줄기) · **nar**(외뿔고래 저격 '끝까지 꿰뚫음' → 레이저 그대로): 레이저.
- 결과 인원: 직사·물수제비·공중·강습 5 / 관통·수중·충격 4 / 투척·원형·집속·레이저 2. 소수 계열은 신규 선원(2차)로 채울 수 있다.

## 2. 엔진 (S5)
1. **출격 상태**(강습·공중): Gun.sortie {phase: out|strike|back, ticksLeft, 목표 자리}. 출격 중엔 다시 쏘지 않고, 쿨은 **복귀 뒤** 시작. 이벤트 `CrewSortie(crewId, phase, fromX, fromY, toX, toY, ticks)` — 렌더가 선원 초상/몸을 그 길로 날린다. 맞힘은 strike 틱(지금 Damage 그대로).
2. 새 모양: `ring`(n방향 직선 탄 — 탄마다 처음 닿는 적, 탄 비행 v2 재사용), `cluster`(본탄 비행 → 도착 때 자탄 k발 산개점 결정론 난수 → 0.1초 간격 각 소폭발), `laser`(직선 빔 지속 ticks, 매 틱 빔 위 관통 수만큼 피해 나눔, 무제한 = 화면 끝까지).
3. 기존 계열 연출용 타이밍: 직사 `burst` 5(0.08초 간격 Damage), 물수제비 튕김 지연(hopSec), 충격 링 도달 지연(거리 ÷ 링 속도), 수중 어뢰 그림자(비행 중 조준 불가 표식). 모두 AttackFired에 선택 키(`burst`, `hopTicks`, `ringSpeed`, `submerged`).
4. 표: skills.json 계열 `behavior` {kind, …}(없으면 지금 그대로 — 단계적 적용), 등급별 값은 ladder(`ringCount`, `bomblets`, `laserPierce`).
5. 결정론 유지, 150마리·11계열 한 틱 < 2ms.

## 3. 연출 (S3)
- 출격: 선원 초상(원형 테 + 등급색)이 배에서 튀어나가 꽂힘(먼지·물보라·휘두름 궤적) → 복귀. 공중은 하늘로 작아졌다 커지며 급강하.
- 투척 포물선 + 땅 그림자, 기관포 총구 섬광·탄피, 작살 줄, 물수제비 물튀김 점, 어뢰 물밑 그림자·솟구침 기둥, 파동 링(퍼지는 원), 링 탄막(사방 탄), 집속 자탄 산개·연쇄 폭발, 레이저 빔(코어 흰색 + 계열색 테, 0.4초).

## 4. 카드·상세 (S4)
- 계열 아이콘 11개 + 한 줄(예: '직접 날아가 베고 돌아온다', '사방으로 가시를 뿌린다', '화면을 가르는 빛'). 상세에 등급별 발 수·자탄·관통.

## 5. 균형 (S2)
- 같은 등급 ±10%(무리전·보스전 평균, 장면별 0.6배 하한 유지). 강습은 쿨 ×2.5라 보스전 강·무리전 약이 자연스럽다 — 역할 표시.
- 출격 중 빈 시간·레이저 지속 피해·자탄 산개 명중률을 balance arena에 포함.

## 수용 기준
1. 계열마다 이벤트로 구분되는 행동(출격 3단계·링 n발·자탄 k발·빔 지속 틱 등) 단위 테스트.
2. behavior 없는 표 = 지금 결과 그대로.
3. 등급별 발 수·자탄·관통이 표대로(레이저 신화 = 화면 끝까지).
4. balance crews 등급별 ±10%, sim 7.2 통과.
5. 렌더 골든 11계열(S3), 카드 아이콘 ko/en(S4).

## 결정 필요 (사용자) — 추천 포함
1. **새 계열 선원 배정**: 원형 탄막 = puffer·uni, 집속탄 = volke·starry, 레이저 = lamp·nar. → **추천: 그대로**(그림이 행동을 바로 말한다). 바꾸고 싶은 선원이 있으면 지정.
2. **출격 계열**: 강습만 vs 강습 + 공중(하늘 급강하). → **추천: 둘 다** — 강습은 '돌진·휘두름', 공중은 '급강하 폭격'으로 같은 기계를 다른 그림으로.
3. **쿨 차이 크기**: 강습 ×2.5(약 5~6초 한 방) vs ×2.0(덜 극단). → **추천: ×2.5**(사용자 '쿨 길고 강력' 그대로, DPS는 같게).
4. **레이저 신화 '무제한 관통'**: 화면 끝까지 vs 상한 10. → **추천: 화면 끝까지**(신화의 홀리는 임팩트).
5. **원형 탄막 발 수**: 일반 8 → 신화 24. → **추천: 그대로**(신화는 화면을 탄으로 채움, 렌더 부하는 S3 측정).
6. **투척 2명만 남음**: 그대로 vs 다른 계열에서 1명 옮김(예: lobster 집게 투척). → **추천: 그대로 두고 2차 신규 선원으로 채움**.
