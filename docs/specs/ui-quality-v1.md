## 도트 규칙 (scene3.py에서 그대로)
1. **정수배**: 논리 320 폭 기준 화면 배율 `k = floor(화면폭 / 320)`(최소 1). 프레임 두께·여백·아이콘·초상은 k의 정수배, 이미지는 nearest(`FilterQuality.none`).
2. **팔레트**(`ui/pixel/palette.dart` 한 곳): 바탕 남색 (24,30,52) · 테두리 (60,70,110) · 윤곽 (27,23,38) · 글자 흰색 · 골드 (242,201,76) · 함성/위험 (255,90,90) · 강조 (255,210,63) · 슬롯 바탕 (150,176,214) · 등급색은 `rarities.json` 그대로.
3. **글자**: 숫자·라틴은 렌더와 **같은 3×5 글리프**(scene3 `GLY`, 윤곽 1px)를 공유 — S3이 `render/` 안 공용 파일로 두고 UI가 import(요청 ①). 한글은 OFL 픽셀 폰트(Galmuri11 제안) — 에셋·pubspec·LICENSES.json은 UI 레인 밖이라 요청 ②. 폰트가 오기 전에는 기존 글꼴.
4. **프레임**: 9-slice 도트 프레임을 그림 파일 없이 그린다(CustomPainter: 윤곽 1px + 테두리 1px + 안쪽 1px 하이라이트, 모서리 1px 깎기, 모두 ×k). 버튼은 눌림 때 1px 내려가고 어둡게. 최소 48dp(접근성 — 미뤄 둔 점검을 이때 같이 통과).
5. **아이콘**: Material 아이콘 대신 도트 — 탭 바는 배·선원 초상·소환 카드·키(지도) 도트 아이콘(가능하면 기존 sprites, 없으면 아트 요청), 골드·젬은 코인/보석 스프라이트.
6. 그림자·둥근 모서리·잉크 물결 없음.

## 화면별
- **탭 바**: 남색 바탕, 선택된 탭은 테두리+밝은 바탕, 도트 아이콘 + 픽셀 글자.
- **배 탭**: 부위 줄 = 도트 프레임 카드, 레벨·효과는 3×5 숫자, 강화 버튼은 골드 코인 + 숫자.
- **선원 탭**: 카드 = 등급색 도트 테두리, 초상 32px ×k(nearest), 별은 도트 별, 승급 빨간 점은 2×2 도트.
- **소환 탭**: 1회·10회 도트 버튼, 확률표·천장 막대 도트.
- **항해 탭·시트·팝업·설정**: 같은 프레임·팔레트.
- **캔버스 위 탭 영역**: S3 HUD와 겹치는 자리(궁극기 = 함성 막대 위, 톱니 = 오른쪽 위 구석)는 투명 탭 영역 + 눌림 표시만.

## 수용 기준
1. 팔레트·정수배 배율 단위 테스트(320→k: 360→1, 640→2, 1080→3).
2. 도트 프레임: 같은 k에서 테두리 두께가 k의 정수배(골든으로 확인).
3. 화면마다 영어 골든 갱신 + **기준 gif 프레임과 나란히 붙인 비교 이미지**(`docs/specs/ui-quality-v1/compare_*.png`, 사람 확인용)를 보고에 첨부.
4. 캔버스 위 위젯은 누르는 것만 남는다(S3 전환 뒤): 골드·젬·스테이지·함성 막대 위젯 없음 테스트.
5. 접근성: 미뤄 둔 48dp·라벨 점검을 도트 버튼으로 통과.
