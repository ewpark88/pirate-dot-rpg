## 1. 무엇을 바꾸나 (5가지)
| # | 항목 | r1 (지금) | r2 제안 |
| --- | --- | --- | --- |
| 1 | 패널 깊이감 | 흰 판 + 그림자 한 겹 | 위 흰색 → 아래 연하늘 그라데이션, **아래 3dp 진한 테두리**(떠 있는 판), 안쪽 위 하이라이트 1.5dp, 그림자 두 겹(넓게 흐린 것 + 바로 아래 진한 것), 카드 머리띠(제목 줄 옅은 파랑) |
| 2 | 뱃지 통일 | 점 크기·위치가 화면마다 다름(PixelDot, 상점 점, 금색 알약 섞임) | **하나의 빨간 알약**: 점 / 숫자(1~9, 10+) / NEW. 흰 테두리 2dp, 위→아래 빨강 그라데이션, 자리는 오른쪽 위 (-6, -6). 처음 나타날 때 한 번 통 튄다 |

| 5 | 보상 반짝임 | 숫자만 바뀜 | 받은 숫자 둘레에 별 4~6개가 0.8초 반짝 + 숫자가 굴러 오름(전투력 표시와 같은 방식). 상자 팝업·출석·퀘스트 받기·환생 상자에 같은 위젯 |

## 2. 어디에 적용하나 (화면별)
- 공용 위젯부터: `SkinCard`(→ 1), `PixelDot`·도크 점·상점 점(→ 2, `SkinBadge` 하나로), `SkinButton`(→ 3), `showPixelSheet`·`PixelDialog`(→ 4), 새 `RewardSparkle`(→ 5). 공용 위젯이 바뀌면 화면은 거의 그대로 따라온다.
- 화면별 확인: 배 탭(부위 줄 카드·배수 알약), 선원 탭(머리 카드·PB 카드 뱃지), 소환 탭, 항해 탭(해역·상태·환생 카드), 상점·스킨·칭호, 상단 바 알약, 도크, 설정, 출석·퀘스트 시트, 오프라인 보상, 소환 결과.
- 바꾸지 않는 것: 색 토큰(r1 승인값), 글꼴(Jua + 기호 보충), PB 카드 그림, 전장(렌더 몫).

## 3. 지키는 것
- 글자 대비 4.5:1, 누르는 곳 48dp, 화면 낭독 라벨(지금 테스트 그대로 통과).
- 끝이 있는 애니메이션만 쓴다(빛 줄기는 '3초마다'지만 화면에 보일 때만 돌고, 테스트에서는 `TickerMode`/설정으로 끈다). 절전 모드·'번쩍임 끄기'면 빛 줄기·반짝임을 끈다.
- 성능: 그림자 두 겹은 카드에만, 목록 칸(선원 카드 40장 등)에는 한 겹. 전장 위 HUD는 그대로.
- 4기기 골든(360/384/411/800×1280) + S24 비교.

## 4. 순서 (승인 뒤)
1. 공용 위젯 r2 (SkinCard·SkinBadge·SkinButton 광택·시트 전환·RewardSparkle) + 단위 골든.
2. 화면 골든 갱신 + S24 비교 그림.
3. 소리: 버튼 '톡'(pop 높은 음) — audioPort 연결, 설정 효과음 끔이면 무음.

## 결정 필요 (사람)
- ① 보상 버튼 빛 줄기 주기 3초가 괜찮은가(너무 잦으면 5초).
- ② 버튼 누름 소리를 모든 버튼에 넣을지, 주 버튼(파랑·금색)에만 넣을지 — 추천: 주 버튼만.
- ③ 뱃지에 숫자를 보일 곳: 추천 = 선원(합치기 가능 수)·퀘스트(받을 수 있는 수)만, 나머지는 점.
