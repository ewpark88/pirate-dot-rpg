# 기획 메모: 보스 특성 (S2, 사용자 요청 #25)

- 상태: **초안(2026-10-17)** → S1 → 사용자 확인 · 수치·배치·sim S2 · 엔진 S5 경로(review 브랜치) · MISS·막 연출 S3 · 약점 표시 S4
- 사용자 원문: "보스 특성도 다양했으면. 폭탄을 특정 확률로 회피하는 보스도 있어야 함. 밸런스 생각하면서 특성 추가".
- 목표: 보스마다 '어떻게 잡아야 하나'가 달라 **편성을 바꿀 이유**가 생긴다. 다만 어떤 편성도 막히지 않게 — 특성 보스의 평균 처치 시간은 특성 없는 보스와 같게(±10%), 카운터 편성은 눈에 띄게 빠르게(+15% 이상).

## 1. 특성 7개
| id | 이름 | 규칙(제안 수치) | 카운터(약점 표시) | 약한 편성 |
| --- | --- | --- | --- | --- |
| `evade` | 회피 | 단일 탄(직사·관통·물수제비·공중·강습)을 25% 확률로 MISS. 범위 피해(투척 폭발·집속 자탄·원형·충격 링·레이저 빔·수중)는 항상 맞는다 | 투척·집속·원형·충격·레이저 | 단일 탄 위주 |
| `armor` | 장갑 | 한 번 맞을 때 피해 − (보스 최대 HP × 0.0015), 최소 25% — 작은 타격 여러 번은 깎이고 큰 한 방은 거의 그대로 | 관통·레이저(느리고 센 공격), 치명타 | 직사 연사·물수제비(작은 타격) |
| `regen` | 재생 | 초당 최대 HP 1.5% 회복. 기절·쓰러짐(브레이크)·화상 중엔 멈춘다 | 제어 선원(브레이크 게이지와 이어짐), 화상 | 제어 없는 편성 |
| `reflect` | 반사막 | 8초마다 예고 0.6초 → 2초 반사막: 그동안 맞은 피해는 0, 그 10%를 배로 되돌림(한 대 상한 shipHitCap 그대로) | 수중(아래에서)·공중(위에서)은 막을 지나간다 | 수상 직사 위주 |
| `enrage` | 분노 | HP 30% 아래로 패턴 쉼 × 0.6, 공격 × 1.3 (보스전 배 피해가 커진다) | 보호막(turtle)·회복 선원, 마지막 30%를 빨리 — 브레이크로 쓰러뜨리면 분노 패턴도 멈춤 | 배가 약한 편성 |
| `escort` | 호위 | 등장·HP 50%에 호위 3마리(보스 둘레를 돈다). 호위가 하나라도 살아 있으면 보스가 받는 피해 × 0.5 | 원형·충격·물수제비(연쇄)·투척 — 호위 정리 | 단일 대상 |
| `dash` | 가속 | 6초마다 궤도 위 다른 자리로 빠르게 이동(속도 × 4, 1초) — 느린 탄·예측 없는 탄은 빗나간다 | 레이저(즉시)·직사(빠른 탄·예측)·공중(따라감) | 느린 투척·물수제비 |

- 사용자 예시 '폭탄을 회피' = `evade`. 투척(폭탄)은 범위라 회피를 못 하는 것이 공정하지만, **사용자 말대로 '폭탄을 피하는 보스'도 있게** `evade`에 선택 키 `evadeArea`(범위도 n% 회피, 기본 0)를 둔다 — 폭풍 해역 `twister_dolphin`만 `evadeArea 0.25`(대신 단일 탄 회피 0, 그때 카운터는 직사·레이저).
- 기존 해역 보스 장치(frontArmor·shield·lava·tentacles·summoner)는 그대로 두고, 위 특성은 새 보스와 일반·중간 보스에 붙인다.

## 3. 밸런스 — 처치 시간 목표 안에
- 측정: `sim --boss-break`와 같은 보스전 계측(선원 40명 단독, 불사 보스, 30초 창, L45·L60)에 `--boss-trait <id>`를 더해 특성 켬·끔 피해를 잰다.
- 보정: 특성마다 **보정 배율 = 끔 중앙 피해 ÷ 켬 중앙 피해**를 그 특성 보스의 hpMultiplier에 곱해 평균 처치 시간을 특성 없는 보스와 같게(±10%). 2개짜리는 곱.
- 성립 조건(특성마다): 카운터 계열 중앙 피해가 보정 뒤 +15% 이상, 카운터 아닌 계열 −25%보다 덜 깎임(막히지 않게). 벗어나면 규칙 수치(회피 25%·장갑 0.0015·재생 1.5%…)를 먼저 고친다.
- 전체 목표는 그대로: 보스 처치 10~20초·보스전 배 피해 25~45%·보통 첫 도전 70~85%·10단위 30~50% — 특성 반영 뒤 sim(5명 × 3시간, 야간 100명)으로 확인.
- 분노·반사막은 배 피해를 키운다 → 보스전 배 피해 지표를 특성별로 따로 본다(벗어나면 attack 배율이 아니라 특성 수치로).

## 4. 표·계약 (승인 뒤)
- regions.json `bosses[].traits`: `[{"type": "evade", "chance": 0.25}, …]`(선택 키, 없으면 지금 그대로). 수치는 S2.
- 약점 표시: 특성의 카운터 계열을 `BossDef.weakFamilies`와 같은 자리로 UI에 보낸다(지금 약점 UI 재사용) — 새 키 `counterFamilies`(표에서 특성으로 계산, 계약 추가).
- 이벤트: 회피 = 기존 MISS 이벤트에 `reason: 'evade'`, 반사막 = `BossShieldUp(enemyId, ticks)`(새로), 호위 = 기존 소환 이벤트. 연출은 S3(회피 잔상·막·호위 원).
- 엔진: topdown 보스(S5 경로) — review 브랜치, 결정론·표 키 없으면 지금 그대로.

## 결정 필요 (S1 → 사용자)
1. 특성 7개 그대로 갈지(빼거나 더할 것).
2. '폭탄 회피' — `evadeArea`를 한 보스(twister_dolphin)에만 둘지, 회피 보스 전부 범위도 조금(10%) 피하게 할지. **추천: 한 보스만**(투척이 회피 보스의 정답이라는 규칙이 흐려지지 않게).
3. 특성 이름·약점 문구를 보스 컷인(등장 이름표)에 같이 띄울지 — **추천: 띄운다**('회피! 범위 공격이 잘 통한다' 한 줄).

## 수용 기준
1. 특성 표가 없으면 전투 결과가 지금과 바이트 동일.
2. 특성마다 규칙대로 동작(단위 테스트: 회피 확률·장갑 하한·재생 멈춤·반사막 0 피해·분노 문턱·호위 피해 감소·가속 이동).
3. 계측: 특성마다 보정 뒤 평균 처치 시간 ±10%, 카운터 +15% 이상, 비카운터 −25% 이내.
4. sim: 특성 반영 뒤 보스 지표(처치 10~20초, 첫 도전 70~85·30~50%, 배 피해 25~45%) 유지.
