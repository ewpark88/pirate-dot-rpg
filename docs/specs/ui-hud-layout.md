# HUD 배치 안 — 상태바·메뉴바 위치 검토 (S4, 2026-10-17)

**결정(사용자 2026-10-17): 떠 있는 띠 + 얇은 도크.** 다른 안·운영자 토글 코드는 지웠다(kDockHeight 58, 진행 게이지 판 없음). 아래는 검토 기록.

사용자: "상태바와 메뉴바 위치를 더 좋은 곳으로 — 가능한지 검토". 지금 배치와 대안 3개를 같은 앱 안에 넣었다.
운영자 패널 → 렌더 → **HUD 배치 안**에서 폰으로 바로 바꿔 볼 수 있다. 사용자가 고르면 그 하나만 남기고 나머지는 지운다.

시안(시험 화면이라 전장 그림은 비어 있다 — 실제 가림 정도는 폰에서 보기):
- `ui-hud-layout/hud_layout_384.png` · `_360.png` · `_tablet.png` (왼쪽부터 지금 · 엄지 · 떠 있는 띠 · 얇은 도크)
- 기기별 원본: `apps/game/test/goldens/hud_layout_<안>_<기기>.png`

| 안 | 바뀌는 것 | 좋은 점 | 아쉬운 점 |
| --- | --- | --- | --- |
| 지금 | 위 막대 · 위 진행 게이지(남색 판) · 아래 도크 76dp | 익숙함, 정보가 위에 모임 | 위쪽 판 두 겹이 전장 윗부분을 가림 |
| 엄지 | 진행 게이지를 도크 바로 위(엄지 영역)로 | 위쪽 전장이 넓어짐, 피버·보스 막대를 엄지 가까이서 봄 | 아래가 무거워짐, 전장이 아래에서 62dp 줄어듦 |
| 떠 있는 띠 | 진행 게이지 판을 없애고 글자·막대만(외곽선) | 전장이 덜 가려짐, 배치는 그대로라 덜 낯섦 | 밝은 바다 위에선 막대 대비가 약해질 수 있음(실기기 확인 필요) |
| 얇은 도크 | 도크 76→58dp, 고른 탭만 이름 | 전장이 아래로 18dp 넓어짐 | 탭 이름이 안 보여 처음엔 헷갈릴 수 있음(아이콘만) |

추천: **떠 있는 띠 + 얇은 도크**를 함께(가림이 가장 적음). 탭 이름은 처음 3분 동안만 모두 보이게 하는 절충도 가능.
