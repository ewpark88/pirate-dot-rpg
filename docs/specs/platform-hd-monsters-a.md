# HD 몬스터 설계 노트 A — 산호·폭풍·빙하 해역 잡몹 13장 (S5)

S1 지시 2026-10-17 · 사용자 결정 'HD로 전부'. S3 공용 벡터 도구·기준서가 오면 이 노트대로 그린다.
짝 노트: S2 `docs/specs/economy-hd-monsters-b.md`(화산·심연·유령) — 같은 표 형식.

## 공통
- 지금 그림: `apps/game/assets/enemies/td_<id>.png` — 16×16 두 프레임(32×16). HD는 S3 기준서의 크기·프레임 수를 따른다.
- 역할은 표(`packages/game_data/tables/regions.json` enemies의 role·layer·ranged)에서 그대로 — **실루엣만 보고 역할이 읽혀야 한다**:
  - **split(분열)**: 몸에 금·이음매가 보이고, 쪼개질 자리가 미리 보인다. 작은 것(`_small`)은 같은 모양 반 크기 + 금 없음.
  - **tough(단단함)**: 넓고 낮은 몸, 두꺼운 등딱지, 테 두껍게.
  - **fast(빠름)**: 길고 가는 몸, 앞으로 기운 자세, 꼬리 잔상.
  - **revive(부활)**: 몸 안에 빛나는 '심지'(혼불·등불·핵) 하나 — 부활할 때 그 자리에서 다시 켜진다. 같은 색으로 통일: 해역 강조색의 밝은 판.
  - **air(공중)**: 펼친 날개, 그림자를 몸 아래 떨어뜨려 그린다(바다 위에 떠 있음).
  - **ranged(원거리)**: 쏘는 부위(입·끝)를 강조색으로, 쏘기 직전 프레임에 그 부위가 밝아진다.
  - **layer underwater(수중)**: 물속 실루엣 — 몸 아래쪽이 물빛으로 옅어지고 거품 2~3개.
- 해역 바탕색(바다 v2 팔레트 `fx_map topSea.regions` 위에서 튀게): 산호 = 밝은 청록 바다 위 산호 분홍·주황 + 모래 노랑 / 폭풍 = 어두운 회청 바다 위 먹구름 회색 + 번개 노랑 / 빙하 = 하늘색 바다 위 얼음 흰·하늘 + 차가운 남색 그림자.
- 테: 굵은 남흑 외곽선(Skin.outline 계열, k2 UI와 같은 두께 감), 위쪽 광택 한 줄.
- 눈: 해역별로 맞춘다 — 산호 = 큰 동그란 반짝 눈(밝고 귀여움), 폭풍 = 찡그린 눈썹 + 노란 눈동자(성난), 빙하 = 작은 점 눈 + 볼 홍조(동그랗고 차분).
- crab은 산호·폭풍 두 해역에 함께 나온다 — 한 장으로 그리고 산호 색을 쓴다(폭풍 바다 위에서도 읽히는지 확인).

## 그린 뒤 확인
- 같은 해역 4종이 한 화면에서 섞여도 실루엣만으로 구분된다(크기·윤곽이 다르게): 산호 = 넓은 게 · 앞으로 기운 물고기 · 둥근 갓 · 날개 / 폭풍 = 넓은 게 · 가시 공 · 긴 날치 · 꺾인 날개 · 부푼 공(복어 — 성게와 크기·가시 길이로 구분) / 빙하 = 금 간 게 · 길쭉한 펭귄 · 넓은 물범 · 둥근 날개.
- 갈매기 3종(gull·stormgull·snowgull)은 같은 공중 실루엣이되 해역 색·날개 꺾임·몸 둥글기로 서로 다르게.
- 단단함 3종(urchin·puffer·seal)은 넓고 낮게 + 테 두껍게, 원거리(urchin·puffer)는 쏘는 가시 끝 강조색.
- 분열 1종의 `_small`은 부모와 같은 색이고 금이 없다.
- 도감(monster_dex)·전투 두 곳에서 본다 — 도감은 큰 그림이라 부품이 다 보이고, 전투는 작아도 실루엣이 읽혀야 한다.
