# 설계 메모: 요일 던전 — 장면 모드 재사용 (콘텐츠 v2 3순위)

- 상태: **설계 메모** (2026-10-18, S5) · 근거: `platform-content-v2.md` 2절 E(사용자 확정 순서: 탑 → 러시 → 요일 던전).
- 재료: 장면 모드 공통부(`scene_mode.dart` — 현상금·탑·러시가 이미 씀), 탑의 무리 파 스폰·층 진행, 스폰 패턴(swarm·scatter·arc·ring), 적 층(surface·underwater·air), 출전 슬롯(`fleet`).

## 1. 놀이
요일마다 **그 날의 계열 선원만** 출전시켜 10단계 던전을 내려간다. 그 계열이 가장 잘 쓸어버리는 모양으로 무리가 온다 —
관통 날은 일렬 행진이 한 줄로 꿰뚫리고, 수중 날은 물속 떼가 장판에 녹는다. **편성 고민 + 그 계열만의 쓸어버림**이 재미.

## 2. 요일과 계열(계열당 선원 수가 고르지 않아 두 계열씩 — 선원 수 표기)
| 요일 | 계열 | 선원 수 | 무리 모양(그 계열이 빛나게) |
| --- | --- | --- | --- |
| 월 | 관통 + 레이저 | 4 + 2 | 일렬 행진(arc 좁게) — 한 줄에 꿰뚫림 |
| 화 | 수중 + 충격 | 4 + 4 | 물속 떼(underwater 층 적)·뭉친 무리 |
| 수 | 공중 + 곡사 | 5 + 2 | 하늘 적(air 층)·멀리서 뭉쳐 옴 |
| 목 | 직사 + 원형 탄막 | 5 + 2 | 사방에서(ring) |
| 금 | 물수제비 + 집속탄 | 5 + 2 | 흩어진 무리(scatter) — 튀는 공격이 이어짐 |
| 토 | 돌격 | 5 | 배에 바짝 붙는 무리(근접) |
| 일 | **아무 계열** | 40 | 섞어서 — 놓친 요일 몰아서(피로 금지) |

- 출전: 그 날 계열 선원 중 보유한 선원만 슬롯에 자동으로(최대 슬롯 수, 강한 순). 하나도 없으면 입장 불가 + '이 계열 선원 얻는 법' 안내.

## 3. 규칙(초안 — 수치는 S2)
| 항목 | 내용 |
| --- | --- |
| 열림 | 탑과 같은 조건(환생 1 또는 스테이지 60) |
| 단계 | 1~10단계(던전 단계마다 기준 스테이지 = 최고 스테이지 × stageRatio + 단계 × stepStage). 한 단계 = 무리 2파 + 단계 보스(그 날 계열 약점 보스) |
| 진행 | 깬 단계 + 1까지 고를 수 있음(현상금 단계와 같은 방식) |
| 보상 | **그 날 계열 선원 카드**(보유 중 무작위, 단계 × cardsPerStep장) + 젬 조금 — 수집과 직결 |
| 도전 | 하루 1회(쌓임 최대 3 — 탑과 같은 규칙), 광고 +1. 깬 단계는 소탕 |
| 젬 | 하루 젬 140은 탑·러시·던전 합(S1 결정) — 던전은 카드 위주, 젬은 작게 |

## 4. 엔진(탑·러시와 같은 틀)
- 세이브 선택 키 `dungeon: DungeonState?` — `tickets`·`refilledOn`·`adOn`·`cleared {요일 묶음 id: 최고 단계}`·`active {group, step}`.
- 명령 `StartDungeon(step)` · `SweepDungeon(step)` · `RetreatDungeon` · 광고 `dungeonTicket`.
- 이벤트 `DungeonStarted(group, step, crewIds)` · `DungeonCleared(group, step, cards[], gems)` · `DungeonFailed(group, step, reason)`.
- BattleView `dungeon {group, step, wave, waves}`.
- 전투 `top_dungeon.dart`: prepare(출전을 그 날 계열로 바꾼 장면 — 끝나면 원래 편성으로, **세이브 fleet는 건드리지 않음**: 전장 무장(_arm)만 임시로), resolve(파 → 보스 → 단계 클리어/침몰), retreat. 무리 모양은 `meta.dungeon.groups[].pattern`·`layer`로 스폰 패턴·적 층을 고른다.
- 편성 임시 교체: 운영자 OpSetFleet이 이미 '고정 출전'을 전장에만 거는 방식(`_fixedFleet`) — 같은 길로 던전 중에만.
- 요일: 현상금과 같은 `weekday`(운영자 고정 OpSetWeekday 재사용).

## 5. 시험
요일 → 계열 묶음(운영자 요일 고정) · 출전이 그 계열만·끝나면 원래 편성(세이브 fleet 그대로) · 단계 클리어 카드가 그 계열 선원 · 열린 단계까지만 · 소탕 · 침몰·그만두기·중단 · 장면 모드 한 번에 하나 · 결정론 · JSON.
